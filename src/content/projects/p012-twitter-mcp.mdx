## 背景

继 B 站知识图谱 MCP 系统之后，我想把同样的思路应用到 X/Twitter——抓取用户时间线，分析内容，同步到飞书知识库。

但与 B 站不同，X/Twitter 没有官方 API（或价格极高），需要用浏览器自动化来模拟用户浏览行为。

## 技术挑战

### 1. 浏览器自动化抓取

使用 Playwright 启动无头浏览器，模拟滚动操作获取推文数据。需要处理：
- X 的 JavaScript 渲染延迟
- 反爬虫检测
- 全量历史数据的深度滚动（可能数千条推文）

### 2. 深度历史抓取

设计了"深度抓取"模式——突破滚动限制，通过分页方式获取账号的全部推文历史。

### 3. 媒体下载

检测推文中的图片和视频，下载到本地缓存，生成索引。

### 4. 飞书同步

将推文内容写入飞书 Bitable 表格 + 云文档，支持增量更新（已同步的不重复写入）。

## 版本演进

这个项目经历了 **6 次架构迭代**（v1.0 → v5.2.1）：


## 技术栈

- **Playwright**: 浏览器自动化，处理 JS 渲染页面
- **SQLite**: 本地数据持久化，增量同步状态管理
- **Pydantic**: 数据模型与类型校验
- **飞书 Open API**: Bitable 表格写入 + 云文档创建/更新
- **进度管理**: 断点续传，支持长时间运行中断后继续
