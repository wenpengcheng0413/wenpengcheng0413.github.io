## 功能模块

7 个页面：概览、分析、品味、最近播放、搜索、数据导入、设置

## UI 亮点

- 1,200+ 行自定义 CSS 注入
- 深色质感主题（Spotify 风格）
- 金银铜排行榜特效 + pulse 动画
- iTunes API 实时获取专辑封面
- 响应式卡片矩阵布局

## 数据流

Apple Music 隐私数据导出 → CSV 自动解析 → SQLite 存储 → Plotly 可视化
